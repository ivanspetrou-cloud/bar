# Bar — нотч для Windows

Чёрная «таблетка» сверху по центру экрана. Наведите мышь — выезжает панель с поиском, плеером,
доком приложений и 16 инструментами. Уведите мышь — панель прячется.

## Установка

1. Скачайте `Bar-Setup-x.y.z.exe` из [последнего релиза](../../releases/latest) и запустите.
   Установка — в профиль пользователя, права администратора не нужны.
2. Установщик не подписан сертификатом, поэтому Windows SmartScreen может предупредить:
   «Подробнее» → «Выполнить в любом случае».
3. Обновления: Настройки → Основное → «Проверить». Bar сам проверяет GitHub раз в 6 часов,
   но скачивает и ставит обновление только по вашей кнопке.

### Расширение «Bar — музыка в браузере» (по желанию)

Нужно, чтобы управлять музыкой в браузере прямо из нотча. YouTube Music — полностью (очередь, библиотека,
поиск, текст, лайки). Яндекс Музыка, SoundCloud, Spotify Web, VK и другие сайты — плеер: обложка, название,
пауза и треки, точная перемотка, громкость. После установки или обновления расширения перезагрузите открытые
вкладки этих сайтов один раз.

1. Трей Bar → «YouTube Music: установить расширение» — Bar подготовит папку расширения
   и скопирует её путь в буфер обмена.
2. Откройте `edge://extensions` (или `chrome://extensions`), включите «Режим разработчика».
3. «Загрузить распакованное» → вставьте путь из буфера.

Расширение обновляется само вместе с Bar. Отдельно скачивать его не нужно: в папке, которую готовит Bar,
лежит секретный ключ пары, уникальный для вашего компьютера.

## Поиск

Поле «Поиск» в шапке раскрытой панели или `Win+Shift+F` из любого места. Ищет:
приложения из «Пуска», инструменты и действия Bar, файлы из индекса Windows (тот же, что у поиска в «Пуске»),
историю буфера обмена, считает выражения (`12*7+3`), открывает адреса сайтов.
Понимает запрос в неправильной раскладке (`ntktuhfv` → «Телеграм»).
`↑↓` — выбор, `Enter` — открыть, `Shift+Enter` — показать в папке / закрепить, `Esc` — очистить.

## Главный экран

- **Сейчас играет** — обложка, трек, перемотка, управление (любые плееры Windows; YouTube Music — с режимом музыки)
- **Звук и система** — громкость, микрофон для всех программ, «Не спать», тема Windows, автоскрытие панели задач
- **Устройства** — заряд беспроводных мыши, клавиатуры, наушников (Bluetooth, приёмники Razer и Corsair)
- **Док** — закреплённые программы; «+» добавляет любую, рядом полупрозрачные подсказки —
  то, что вы чаще всего запускаете (по счётчикам самой Windows). Клик по подсказке закрепляет,
  правая кнопка — «Не предлагать».
- **Раскладка** — нажмите на `RU` в раскрытой панели, чтобы выбрать раскладку вручную.

## Игровой режим

В игре на весь экран нотч сам переплывает в выбранный угол и превращается в плашку с FPS, загрузкой
процессора и видеокарты, памятью, пингом и временем; предупреждает о выключенном микрофоне и садящейся
мыши или гарнитуре. Плашка прозрачна для мыши. После игры нотч плывёт обратно наверх.
Настройки → Игры: угол, показатели, «не считать игрой», `Win+Shift+G` — включить или выйти вручную.

FPS считает [PresentMon](https://github.com/GameTechDev/PresentMon) от Intel (лицензия MIT, входит в установщик).
Windows показывает кадры чужих игр только администраторам и группе «Пользователи журналов производительности»:
кнопка «Разрешить FPS» один раз добавляет вашу учётную запись в эту группу (с подтверждением Windows),
после повторного входа в Windows FPS работает без прав администратора.

## Горячие клавиши

- `Win+Shift+B` — открыть нотч
- `Win+Shift+F` — поиск
- `Win+Shift+G` — игровой режим
- `Win+Shift+O` — текст с экрана (OCR)
- `Win+Shift+D` — пипетка
- `Win+Shift+X` — скриншот области
- `Win+Shift+Q` — QR с экрана
- `Esc` — назад / свернуть

Меняются в Настройках → Основное. Ctrl+Alt+буква Bar не принимает: на Windows это AltGr,
им набирают `@ € { } [ ]` на немецкой и многих других раскладках.

## Приватность и безопасность

- **Никакой телеметрии и аналитики.** Bar сам выходит в интернет только в четырёх случаях:
  проверка обновлений на github.com; загрузка обложек YouTube с серверов Google, когда играет YouTube Music;
  поиск в интернете — только если вы сами выбрали эту строку в поиске; замер пинга в игровом режиме —
  TCP-соединение с 1.1.1.1 раз в 3 секунды без передачи данных (выключается в Настройки → Игры → «Пинг»).
- **Всё остальное — локально:** поиск файлов (индекс Windows), подсказки дока (счётчики Windows),
  OCR (встроенный в Windows), заряд устройств.
- **История буфера** хранится зашифрованной (DPAPI Windows, доступна только вашей учётной записи).
  Пароли из менеджеров паролей, которые помечают копирование как приватное, в историю не попадают.
- **Окна Bar** изолированы: песочница Chromium, без Node.js в интерфейсе, строгий CSP,
  переход на чужие страницы и открытие окон запрещены, функции Bar принимают вызовы только от своих страниц.
  Electron Fuses: проверка целостности `app.asar`, запуск как Node и отладочные флаги отключены.
- **Расширение «Bar — музыка в браузере»** работает только на музыкальных сайтах (YouTube Music; плеер — на
  Яндекс Музыке, SoundCloud, Spotify Web, VK, Apple Music, Deezer, Tidal, Bandcamp, Звук, Amazon Music, Mixcloud):
  читает лишь то, что сайт сам передаёт браузеру для мультимедийных клавиш (название, обложка, кнопки) и состояние
  аудиоплеера страницы. Связывается только с Bar
  на `127.0.0.1`; Bar и расширение проверяют друг друга по HMAC с ключом, который не покидает компьютер.
- **Мост с телефоном** включается вручную, работает только в локальной сети по случайному токену
  и сам выключается через 20 минут без использования.
- **Обновления** скачиваются по HTTPS из релизов этого репозитория; целостность файла сверяется по SHA‑512.

## Лицензия

Bar бесплатен для использования, исходный код открыт для просмотра и проверки.
Распространять программу, её изменённые версии и код запрещено — делитесь ссылкой
на [страницу релизов](../../releases/latest). Полные условия — в файле [LICENSE](LICENSE).

## Сборка из исходников

```powershell
npm install
npm start          # запуск в режиме разработки
npm run dist       # установщик в dist\
```

Устройство:

- `src/main.js` — прозрачное окно поверх всех; клики проходят сквозь него, пока мышь не над нотчем. Захват экрана, OCR, трей, горячие клавиши.
- `src/agent.ps1` — постоянный PowerShell-агент: звук, окна, медиа, заряд устройств, раскладки, поиск файлов.
- `src/ui/` — сам нотч (`app.js`), оформление (`theme.js`), оверлей выделения/пипетки (`overlay.js`).
- `src/music.js`, `extension/` — связь с YouTube Music через расширение браузера.
- `src/bridge.js` — локальный HTTP-сервер для телефона.
- `src/updater.js` — обновления из GitHub Releases.

Самопроверка интерфейса: `BAR_SNAP=<папка> BAR_SNAP_STEPS=<сценарий.json> npx electron .` сохраняет скриншоты и выходит.
